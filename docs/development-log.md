# 開発の記録

バージョンごとの品質の仕組みの変更（公開物の変わらない変更）の記録です。1 項目 1 行で、何を足した・やめた・変えたかと、動かし方が変わるなら環境変数・コマンドを書きます（RELEASING.md の「区分」）。利用者向けの変更は CHANGELOG.md にあります。このファイルは npm の公開物に含めません。

0.30.0 から 0.31.0 までの分は、0.31.0 で CHANGELOG.md の各バージョンの「開発」から移しました（移したときは文を変えていない。0.31.2 で用語を「バージョン」にそろえた）。0.29.x 以前の「開発」は CHANGELOG.md の各バージョンにあります。
